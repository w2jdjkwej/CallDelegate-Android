# 已知限制

## 源码快照边界

公开仓库不包含模型权重、AAR、APK、scrcpy-server、录音和设备测试产物。未准备本地资源时，部分功能只能阅读或编译，不能完成真实语音推理。

## 语音与规则

- 能量 VAD 对噪声、远场和说话停顿较敏感；
- Vosk 与 VITS 的准确率、延迟、内存和稳定性取决于设备与音频条件；
- 规则 NLU 和 JSON 状态机只覆盖有限场景，不是开放式聊天模型；
- 模拟输入和文本测试不能替代真实麦克风、真实通话或目标设备验收。

## Android 通话能力

- Shizuku/scrcpy 方案依赖 shell 权限、隐藏 API、Android 版本和厂商音频策略；
